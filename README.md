# deskbar

A tactical calendar dashboard for an 8.8" 1920×480 ultrawide touchscreen, driven by a Raspberry Pi Zero 2 W. Multi-account Google Calendar swimlanes, flip-clock panel, and weather — rendered by a single lightweight Pygame process (no desktop environment, <200MB RAM).

樹莓派 Zero 2 W ＋ 8.8 吋長條觸控屏的桌面行事曆儀表板：多 Google 帳號泳道時間軸、大字時鐘與天氣，單一 Pygame 程序直繪 framebuffer。

**Status**: design complete — see [design spec](docs/superpowers/specs/2026-07-26-deskbar-design.md); implementation in progress.
